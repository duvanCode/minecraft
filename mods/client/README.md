# Mods del cliente

Esta carpeta es para el pack recomendado que cada jugador debe copiar a su PC para entrar al server con la misma base de mods.

Ruta habitual en Windows:

```text
%APPDATA%\.minecraft\mods
```

Ruta habitual en Linux:

```text
~/.minecraft/mods
```

Ruta habitual en macOS:

```text
~/Library/Application Support/minecraft/mods
```

## Mods recomendados para el PC

- `fabric-api`
- `modmenu`
- `sodium`
- `lithium`
- `ferrite-core`

## Nota

- Con la seleccion basica propuesta, los mods del cliente son un pack recomendado.
- Si agregas mods que sean obligatorios en cliente, ponlos tambien aqui para que todos usen el mismo pack.
